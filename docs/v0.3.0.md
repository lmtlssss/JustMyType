# v0.3.0 observed proof

These are public synthetic measurements from the v0.3.0 source and live
recipe checks. They are not total workflow cost savings and do not prove every
platform runtime.

- 157 source tests passed.
- Three typed judgments used one evaluation: 409 input tokens and 68 output
  tokens.
- An exact repeat returned a cache hit with zero current tokens.
- Metadata selection measured two candidates, 477 input and 30 output tokens,
  while preserving protected text verbatim.
- A provider-rounded score of 3.78 versus 3.80 exposed a precision bug; the
  regression was repaired and covered.

The 30-repository source review is documented in [the ecosystem review](jev-ecosystem.md).
Existing guard policy, model, permissions, and native hooks remain unchanged.
There is no automatic compaction or model router.
