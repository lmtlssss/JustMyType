# 0.2.0

Jev reads the rule. Python compares the values.

## change

The original whole-action check remains. Numeric and date limits now have a
separate path. Code finds literal bounds in the user's instructions and existing
values in tool arguments. Jev selects the field, comparison operator, action
stage, and approval requirement. A separate check resolves later instructions
that replace or waive an earlier rule. Code then performs the exact comparison.

For example, 10,001 cents is greater than $100. The comparison is not another
model judgment. An action that only previews a refund is not a payment. A later
explicit exception can change which rule applies.

Each result retains the selected field, original bound, comparison, and model
signals. A native denial includes the exact comparison that caused it.

## execution

Independent requests use up to four threads and share a six-second deadline.
A normal action without a supported numeric rule uses the original request.
For N supported numeric rules, the assessment uses N + 2 logical requests:
one original check, N isolated rule checks, and one authority check. The existing
bounded HTTP retry can add a transport attempt. There is no cached approval.

A proven block remains a block if another independent request fails. An incomplete
assessment cannot become a pass. Native reviews and unavailable assessments still
produce notices rather than blocking; CLI guard still runs only a pass. No native
approval or sandbox setting is weakened.

## limits

The added path handles one literal boundary per rule, scalar fields in JSON
objects, ISO calendar dates, and unambiguous literal shell flags. It does not
compute list totals, infer exchange rates, evaluate shell code, resolve arbitrary
formulas, or prove general program correctness. Complex rules use the original
check. The binding choices can still be wrong.

The added path does not cancel an unrelated block from the original check.
Existing false positives therefore remain possible. The tests found them and
retain them. This is a scoped capability improvement, not a claim of universal
accuracy or lower cost.

`engine_sha256` covers the runtime, binding module, and policy. The installer
includes that same module on all three operating systems. The explicit Machine
CLI uses the same engine as native Codex hooks.
