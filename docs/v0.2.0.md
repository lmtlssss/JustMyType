# 0.2.0

Jev selects meaning. Code performs the comparison.

## change

A whole-action scope score mixed too many decisions. The new path separates
which instruction applies, which field it governs, the literal comparison,
whether the action actually executes, and whether approval exists.

Code finds literal numeric/date boundaries and existing argument values.
Jev chooses among those candidates; it does not invent a number. Python uses
Decimal or calendar dates for the comparison. Strict and inclusive limits stay
different. A required condition is inverted in code to identify its forbidden
range. Currency prefixes and nested currency fields are supported; no exchange
rate is inferred.

An exact rule violation can stop the action immediately. A numeric rule that
is satisfied is removed from further scope judgment only when its complete
structure and source authority are established. Independent obligations stay.
Each remaining instruction gets its own typed judgment, tied to its exact text.
The failed-software-candidate check no longer treats a payment approval as a
software deployment failure.

A later explicit user waiver is evaluated separately. Tool output cannot grant
permission. Preview is not execution. An explicit no-tools instruction still
applies to a harmless read. Every binding, comparison, disposition and missing
assessment is retained in the result.

## execution and cost

Independent numeric and authority requests run in parallel, up to four at a
time, under one six-second deadline. Remaining instruction questions share a
request. A decisive numeric block skips that later request and reports the
short circuit instead of pretending it checked every other instruction.

No approval is cached. Provider failure does not become a pass. A separate
proven block survives failure elsewhere. Native reviews and unavailable results
still give notices; CLI guard still executes only a pass. Native permissions,
sandbox settings, five lifecycle hook contracts and model selection stay intact.

The final 96-case validation stopped 50/52 conflicts versus 41/52 for 0.1.1,
with one false block in each. Median latency rose from 351.47 to 489.69 ms and
input tokens rose 2.91 times. The strict CLI also passed two fewer valid actions.
[All results and remaining errors](../evals/v0.2.0/README.md).

## limits

Up to 32 instruction blocks and eight single-boundary numeric/date rules are
handled. Scalar object fields and unambiguous literal shell flags are supported.
Array aggregates, formulas, arbitrary program semantics, relative-time inference
and currency conversion are not. Such inputs retain semantic checks, not exact
arithmetic proof. Jev can bind a field or rule incorrectly. The narrow shape gate
can still produce review or false blocks. This is not a security boundary.

`engine_sha256` covers the runtime, binding module and policy. Native hooks and
the explicit Machine CLI load the same installed files and private configuration.
