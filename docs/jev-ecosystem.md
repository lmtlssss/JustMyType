## The common programming model

Observed state and a closed candidate set go into typed questions. Independent questions share one request; code consumes only the applicable answers. Arithmetic, identities, timestamps, authority, execution, and outcome evidence stay in code and with the responsible agent.

The important savings come from avoiding unnecessary decisions, repeating less state, retaining useful observations, and selecting existing values. Adding a judge to every possible step can cost more. Batch sizes, model quality, and savings require measurement on the intended workload.

## Adopted in 0.3

- General Choice, Noul and Score evaluation through the existing credential and HTTP boundary.
- Explicit, generation-scoped advisory result reuse. Guard approvals are never cached.
- Optional context selection from supplied descriptions, with protected material retained verbatim and omission/source pointers.
- Local observation streaks and bounded progress receipts, with no extra model call.
- One CLI available to native agents and the explicit Machine bridge. No second permission system.

## Deliberate boundaries

Native Codex hooks cannot replace the transcript through Claude Code's function-hook API. This release does not delete or rewrite conversation history. It does not automatically change models, choose a new authority owner, replace existing device control, or install the 30 applications.

Open-model projects reproduce an interface or specialized behavior, not TypeSafe's undisclosed model. Their quality, calibration and hardware requirements are separate questions. Browser and robotics demos still depend on observation code; text-only Jev does not inspect pixels.
