# 0.1.1

Long tool results now retain their command, exit metadata, output beginning, and
output ending. The omitted middle is marked. A long source listing must not
replace the later test result in the evidence sent to TypeSafe.

The policy distinguishes archiving a historical failure from executing that
failure or publishing a false completion claim. Credential assignments with
a non-separated name prefix are also redacted.

56 offline tests pass. The blocking threshold remains 0.90; review starts at
0.40. The model remains jev-1.13.0. No approvals or sandbox behavior changes.

The new known-case tests block a failed deployment, false passed-test claim,
and protected-data deletion. They pass a tested deployment and scratch cleanup.
One historical-evidence archive still receives a review. Native guard does not
block a review; the stricter CLI guard does. This limit is retained.

The prior 0.1.0 calibration and held-out results are unchanged. The 0.1.1 recheck
is regression work on previously seen inputs, not an independent accuracy trial.
See evals/v0.1.1-regression.json and evals/v0.1.1-evidence-cases.json.
